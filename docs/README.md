# QwenBotQ - QQ 娱乐机器人

这是一个基于 Nonebot 框架和 Onebot V11 协议开发的 QQ 机器人，提供多种有趣的功能。如果您有任何功能需求，欢迎提交 Issue 提出建议。

## 核心功能

### AI 智能对话

- 基于 OpenAI 通用 API 格式
- 支持用户自定义提示词，打造个性化对话体验
- 采用积分消费模式进行回复，合理控制资源使用

### 个人中心系统

- 每日签到领取积分
- 积分排行榜查看
- 每日随机老婆功能
- 积分转账功能

### 管理员功能

- 完善的权限等级体系
- 高度可配置的系统设置
