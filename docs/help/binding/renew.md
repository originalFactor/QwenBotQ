# 续期 CP 绑定关系

## 使用方式

```
续期
```

用于为您当前的 CP 绑定关系续期。

## 参数说明

无参数要求，直接发送命令即可。

## 积分要求

| 属性     | 要求                  | 说明                     | 默认值 |
| -------- | --------------------- | ------------------------ | ------ |
| 消耗积分 | >= renew_cost(默认 1) | 执行此命令需要消耗的积分 | 0      |

## 回复格式

```
@你的昵称
已成功续期您和
{绑定用户昵称} ({绑定用户ID})
的关系至
YYYY/MM/DD
```
