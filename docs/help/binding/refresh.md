# 换老公

```
换老公
```

解除当前绑定关系

## 发送人用户信息
| 属性 | 要求                    | 解释     | 默认 |
|------|-------------------------|----------|------|
| 积分 | >= `refresh_price`(默认`1`) | 消耗积分 | `0`  |

## 返回
```
@sender
已解除绑定！
```
