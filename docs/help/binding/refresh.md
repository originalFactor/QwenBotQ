# 解除 CP 绑定关系

## 使用方式

```
换老公
```

用于解除您当前的 CP 绑定关系。

## 参数说明

无参数要求，直接发送命令即可。

## 积分要求

| 属性     | 要求                     | 说明                     | 默认值 |
| -------- | ------------------------ | ------------------------ | ------ |
| 消耗积分 | >= refresh_price(默认 1) | 执行此命令需要消耗的积分 | 0      |

## 回复格式

```
@你的昵称
已解除绑定！
```
