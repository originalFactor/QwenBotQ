# 随机绑定今日 CP

## 使用方式

```
今日老公
```

随机为您匹配并绑定今日的 CP 关系。

## 参数说明

无参数要求，直接发送命令即可。

## 回复格式

```
@你的昵称
你今天的老公是：
[头像图片]
{绑定用户昵称} ({绑定用户ID})
过期时间：YYYY/MM/DD

今日关系已绑定，要好好珍惜哦！
```
