# 群友列表

```
群友列表
```

获取当前群组的所有成员列表

## 返回
```
@sender
{nickname1} ({user_id1})
{nickname2} ({user_id2})
{nickname3} ({user_id3})
...
```

## 注意事项
1. 只能在群聊中使用
2. 显示群内所有成员的昵称和QQ号
3. 按照群成员列表的顺序显示
