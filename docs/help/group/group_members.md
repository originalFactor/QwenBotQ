# 查看群成员列表

## 使用方式

```
群友列表
```

用于获取当前群组的所有成员列表。

## 参数说明

无参数要求，直接发送命令即可。

## 回复格式

```
@你的昵称
{成员昵称1} ({成员ID1})
{成员昵称2} ({成员ID2})
{成员昵称3} ({成员ID3})
...
```

## 重要提示

1. 此功能只能在群聊中使用
2. 会显示群内所有成员的昵称和 QQ 号
3. 成员列表按照群内成员顺序显示
